# Lean module guide

Import `NilBohr` to use the entire development. The [manuscript map](PAPER_MAP.md) links numbered results and substantial unnumbered claims to their Lean declarations. The [assumption catalogue](ASSUMPTIONS.md) gives the analytic inputs and identifies the checked application steps.
